# 😊 Facial Emotion Recognition using CNN

A deep learning-based project to classify facial emotions using Convolutional Neural Networks (CNN).

---

## 📌 Overview

Facial emotions are key to human interaction. This project aims to recognize facial emotions automatically using a CNN trained on the Kaggle FER dataset.

---

## 🧰 Requirements

- Keras (with TensorFlow backend)
- OpenCV
- NumPy
- Pandas
- Matplotlib

Install via pip:

```bash
pip install tensorflow keras opencv-python numpy pandas matplotlib
